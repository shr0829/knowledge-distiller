# 知序前端

React / TypeScript / Vite 本地审核界面，使用官方 Fluent UI 控件与图标。

## 运行

在本目录执行：

```powershell
npm ci
npm run build
npm run lint
```

构建产物位于 `dist/`，由 Python 本地服务统一提供。使用仓库启动脚本打开的审核 URL；初次会话需要启动器生成的审核凭据。兑换成功后，前端立即清除地址中的凭据，后续使用 HttpOnly 会话 Cookie 与 CSRF 请求头。

开发时可运行 `npm run dev`。Vite 将 `/api` 代理到 `http://127.0.0.1:8765`；必须先运行后端，并通过启动器授权当前浏览器会话。

## 界面范围

- 审核队列：搜索、筛选、来源、正文／目标／链接／标签编辑。
- 精确变更预览与单项确认；批量展示已选版本后逐项写入。
- 冲突后的目标版本刷新，历史记录及校验后的单项撤销。
- 实际 Markdown 笔记与内部链接关系图。
- 有效反馈指标、策略版本、可编辑的策略建议及独立授权范围。
- 项目／模型设置、捕获开关、事件错误查看及提炼重试。

`src/types.ts` 描述 API 数据结构；`src/api.ts` 统一完成会话与错误处理。前端不直接读取知识库、不生成审核批准凭据，也不把合成样本计为真实学习样本。

视觉规范见 `DESIGN.md`。
