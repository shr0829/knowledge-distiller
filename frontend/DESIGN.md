# 知序工作台界面

本地 Codex / Obsidian 知识审核工具，使用官方 Fluent UI React 组件与 Fluent 图标。面向长时间桌面操作，重点是来源、精确版本、差异与明确的人类决定。设计参数为 variance 3、motion 2、density 8。

采用 Segoe UI / Microsoft YaHei 系统字体，白色内容面板、浅冷灰侧栏，以及 `#0f6cbd` 单一品牌强调色。成功、冲突与差异使用有含义的语义颜色。面板圆角 4–7px，主要层级由分隔线、字号与间距表达。

桌面审核页使用左侧项目导航、提案列表与正文审核面板。审核正文内部滚动，底部预览／确认操作保持可见。平板缩减侧栏，手机改为顶部导航与纵向列表／详情。所有自定义交互都有键盘 focus；图谱来自实际笔记链接。

编辑后的正文和目标必须重新预览，保存使用绑定精确内容的 preview token。批量只允许 save / update 推荐项，并显示每项版本与差异。合成演示数据明确标注。学习指标取自后端有效样本口径，授权开关读取已有范围；策略建议仅载入草稿。

验证：TypeScript / Vite build、Oxlint 无警告；Impeccable detector 返回空问题列表。桌面与手机真实浏览器流程由主任务统一验证。
